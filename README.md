# Textile Dye Ratio Mixer

**Category:** Crafts & Textile Arts Tools

Mix multiple dye components with %OWF (On Weight of Fiber) ratios to preview blended colors and calculate exact gram amounts for any fiber weight. Accounts for fiber affinity (wool/cotton/silk/linen/nylon/polyester), mordant effects (alum/iron/copper/tannin), pH adjusters, and temperature. Shows liquor ratio, dye concentration (g/L), shade variation strips at different % OWF, complementary/triadic color harmonies, and saves fully reproducible recipes. All data persists in localStorage.
